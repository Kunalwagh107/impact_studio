2 · Dataset profile

What the app found in each dataset: dimensions, metrics and data quality. Roles are guesses — correct them in the next step if needed.

3 · Market mapping

Pair a market value from the previous dataset with the corresponding value in the updated one, and say which level each pair belongs to. The level you choose is what scopes the analysis — Total Market covers the values you paired as totals. A market need not be named the same in both datasets; that is what the two sides are for. Nothing is paired for you.

4 · Map the categories, then generate the impacts

One action reads the category structure of both datasets and opens the editor. Define how each category in the previous dataset corresponds to the updated one — a single category there, a category plus a subcategory, several of them, or nothing at all. Names are never assumed to be equal, and nothing is mapped on your behalf. When you are done, the impact analysis runs on what you defined. A category you leave unmapped is not analysed: it has no counterpart to compare against.

5 · Analysis selection

Choose the metric and periods on each side, the market, the categories to report, Top-N, and any client entities that must be tracked. The metric is selected independently per dataset — the two need not name it the same way.

Which metric to measure

The categories you confirmed and mapped are the ones that move forward. Choose the impact metric — or several. Each is resolved on both datasets independently, because they need not name it the same way.
